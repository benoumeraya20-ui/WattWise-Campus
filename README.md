
# WattWise Campus 

AI-powered energy monitoring and optimization platform for university buildings.

## Features
- Energy consumption dashboard
- 24-hour energy forecasting using Random Forest
- Anomaly detection using Isolation Forest
- Smart energy-saving recommendations

## Technology Stack
- Python
- Streamlit
- Pandas and NumPy
- Scikit-learn
- Plotly

## Data Disclaimer
This prototype uses synthetic data for demonstration purposes.
No real energy measurements from the University of Saïda are currently used.

## Future Work
Validation with authorized real campus energy data.
